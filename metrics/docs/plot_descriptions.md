# Metric Plot Descriptions

Generated by `metrics/scripts/plot_metrics_demo.py` using a trained agent (checkpoint 198, cmaes_vae_beta2.0, seed 0) rolled out on 16 buffer levels sampled evenly from `buffer_dump_final.npz`.

Plots are saved to `metrics/plots/`.

---

## Figures 1-3: DTW-Based Deep-Dives

**Files:**
- `plots_deepdive_pos.png` — ranked by Position DTW
- `plots_deepdive_action.png` — ranked by Action Distance
- `plots_deepdive_regret.png` — ranked by Regret DTW

Each figure picks the most similar and most different level pair according to that metric. Two rows (similar on top, different on bottom), seven columns:

- **Col 1-2:** Maze grids with agent path overlaid (blue/red, time-gradient opacity). Circle = start, square = end.
- **Col 3:** Position DTW local cost profile (orange, filled).
- **Col 4:** Action DTW local cost profile (green, filled).
- **Col 5:** Regret DTW local cost profile (red, filled).
- **Col 6:** Per-step regret curves for both levels overlaid.
- **Col 7:** Per-step entropy curves for both levels overlaid.

**What to look for:** The most similar pair should show comparable profiles across all columns. The most different pair should diverge. Since each figure ranks by a *different* metric, you can see cases where levels are similar on one axis but different on another — revealing the independence (or correlation) between metrics.

## Figure 4: Value Error Deep-Dive

**File:** `plots_deepdive_value_error.png`

Ranked by pairwise L1 distance of signed value error curves. Shows most similar and most different pairs by how the agent's predictions fail.

Seven columns:
- **Col 1-2:** Maze grids with agent paths.
- **Col 3:** Signed value error curves (V(s_t) - G_t) for both levels overlaid. Dashed line at 0 separates overconfident (above) from underconfident (below).
- **Col 4:** Experience mode sequences as colored horizontal bars (one per level). Colors: green=confident_correct, red=confident_wrong, yellow=uncertain, blue=recovering, purple=degrading.
- **Col 5:** Mode fraction bar chart (side by side comparison).
- **Col 6-7:** Transition probability heatmaps (5×5 matrices) for each level. Cell values show P(next_mode | current_mode).

**What to look for:** Similar value error curves should produce similar mode sequences and transition matrices. The most different pair should show qualitatively different error patterns (one overconfident, one underconfident) and correspondingly different mode distributions. The transition heatmaps reveal whether the agent is stuck in confusion loops (high self-transition on confident_wrong) vs making clean progress (high confident_correct → confident_correct).

## Figure 5: Experience Mode Divergence Deep-Dive

**File:** `plots_deepdive_mode_transition.png`

Ranked by symmetric KL divergence between mode transition matrices — the primary experiential diversity metric.

Same column layout as Figure 4.

**What to look for:** The most similar pair should have near-identical transition heatmaps and mode fractions. The most different pair should show fundamentally different agent experiences: one maze might be dominated by "confident_wrong → recovering" loops (trap maze) while the other shows clean "confident_correct → confident_correct" runs (easy maze). Compare the transition heatmaps side by side — structural differences in the matrices correspond to qualitatively different learning processes.

**Key insight:** Compare Figures 4 and 5 — they often select different pairs, because value error *magnitude* can be similar while the *temporal pattern* (captured by mode transitions) differs. Two mazes with similar mean error but different mode dynamics provide genuinely different learning signals.

## Figure 6: Normalized TD Error Distribution Deep-Dive

**File:** `plots_deepdive_td_error.png`

Ranked by Normalized Earth Mover's Distance between TD error distributions — the most task-agnostic diversity metric (uses only values, rewards, dones). TD errors are normalized by their total absolute sum before comparison, isolating learning signal *shape* from *magnitude* (since SFL learnability handles magnitude).

Seven columns:
- **Col 1-2:** Maze grids with agent paths.
- **Col 3:** TD error time series (δ_t = r_t + γV(s_{t+1}) - V(s_t)) for both levels overlaid. Dashed line at 0.
- **Col 4:** Normalized TD error histograms (overlaid density plots) with EMD value in title.
- **Col 5:** Empirical cumulative distribution functions (ECDFs) of normalized TD errors. The area between the two curves IS the EMD.
- **Col 6:** Absolute TD error |δ_t| over time — learning magnitude regardless of sign.
- **Col 7:** TD error sign balance — horizontal bars showing what fraction of steps have positive (underestimate) vs negative (overestimate) TD errors.

**What to look for:** The most similar pair should have overlapping normalized histograms and CDFs (low EMD). The most different pair should show clearly separated distributions. The time series (col 3) shows *when* the learning signal differs; the histogram (col 4) collapses that into *what shape* of learning signals differ. The sign balance (col 7) reveals whether one maze consistently under/overestimates while the other doesn't.

## Figure 7: Diversity Embedding (t-SNE)

**File:** `diversity_embedding.png`

t-SNE projection of all foreground levels (references, rejected candidates, accepted candidates) with buffer levels as background dots. Generated during each LLM generation batch.

- **References:** Labeled markers (Maze A, B, C, ...).
- **Rejected/Accepted:** Color-coded markers showing gate outcomes.
- **Buffer background:** Grey dots (all buffer levels when `buffer_embed_samples: -1`). Split into gate-pass/fail subsets if scores are available.
- **Edges:** Lines from each rejected/accepted level to its closest reference, annotated with actual EMD/metric distance values.
- **Reference centroid:** Diamond marker at the mean of reference positions.

**Important caveat:** t-SNE preserves local neighborhoods but distorts global distances. Two clusters that appear far apart may not be proportionally far in metric space. The edge annotations show actual metric values to compensate — read the numbers, not the visual distances.

## Figure 8: Diversity Embedding (MDS)

**File:** `diversity_embedding_mds.png`

MDS (Multidimensional Scaling) projection — same content as the t-SNE embedding but with layout that preserves actual pairwise distances. Two levels that are metrically far apart appear visually far apart.

Same markers, edges, and annotations as the t-SNE version. Prefer this plot when interpreting global distance relationships. Use the t-SNE version when interested in local cluster structure.

## Figure 9: Buffer Clusters

**File:** `buffer_clusters.png`

4x4 grid of buffer levels grouped by behavioral clusters, generated by `llm/plot_buffer_clusters.py`. Each subplot shows one maze with the agent's trajectory trace overlaid.

**Cluster groups:**
- **Main Cloud** — typical buffer levels with moderate difficulty and standard behavior patterns.
- **Unsolved** — levels the agent fails to solve (0% solve rate, full-length trajectories).
- **Long Solved Wild TD** — solved levels with long episodes and volatile TD error patterns.
- **Short Miscalibrated** — solved levels with short episodes but large prediction errors.

**What to look for:** Trajectory traces reveal qualitative behavioral differences between clusters — dense wandering loops in unsolved mazes vs direct paths in short miscalibrated ones. The clustering validates that the pairwise distance metric captures genuine behavioral diversity, not just structural maze differences.
