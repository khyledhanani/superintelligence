```python
EXAMPLE_SCRIPTS = [
    "maze_dr.py",
    "maze_plr.py",
    "maze_paired.py",
]

@pytest.mark.parametrize("script", EXAMPLE_SCRIPTS)
def test_run_example(script):
    # Runs each example as a subprocess with 30s timeout
    process = subprocess.run(
        [sys.executable, script_path],
        timeout=30,
        env={**os.environ, "WANDB_MODE": "disabled"},
    )
    assert process.returncode in [None, 0]
```

## Gaps & Recommendations

1. **No unit tests** — entire test suite is integration/smoke tests only
2. **No fixtures** — no conftest.py, no shared setup/teardown
3. **Slow tests** — 30s timeout per subprocess run; no fast unit test alternative
4. **ES pipeline untested** — `es/` directory has no automated test coverage
5. **Coverage metric misleading** — `--cov=src/jaxued` measures coverage of library code, but tests only exercise it indirectly through example scripts
