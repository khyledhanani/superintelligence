## Language & Style

- **Language:** Python 3.9+
- **Type hints:** Used extensively via `typing` module (`Optional`, `Tuple`, `Literal`, `TypedDict`, `Any`)
- **Linting:** flake8 is configured in `tox.ini` but **commented out** — not enforced in CI
- **Formatting:** No enforced formatter (no black/ruff config found)
- **Docstrings:** Present on major classes; use Args/Returns Google-style format

### Example — Docstring style:
```python
class LevelSampler:
    """
    Short description.

    Examples:
        >>> example usage

    Args:
        capacity (int): Description.
        replay_prob (float, optional): Description. Defaults to 0.95.
    """
```

## JAX Programming Model

The codebase follows JAX's functional/stateless paradigm throughout:

### Stateless Classes
```python
class LevelSampler:
    # No instance state — all data passed as arguments
    def insert_batch(self, sampler, level, scores):
        # Returns new sampler (immutable update)
        ...
```

### Flax Structs for Data
```python
from flax import struct

@struct.dataclass
class Level:
    wall_map: chex.Array
    agent_pos: chex.Array
    # Immutable, JIT-compatible dataclasses
```

### `chex` for Array Typing
```python
import chex
levels: chex.Array  # shape (capacity, ...)
```

### `jax.vmap` / `jax.lax.scan` Usage
- Vectorized operations preferred over Python loops
- `partial` used to freeze non-array arguments before `vmap`/`jit`

## Error Handling

### Pattern: Generic Exception (current state — flagged as concern)
```python
try:
    ...
except Exception as e:
    raise Exception(f"Descriptive message: {e}")
```

### Pattern: Assert for Invariants
```python
assert level.wall_map.shape == expected_shape, "Shape mismatch"
# Note: disabled by Python -O flag in production
```
