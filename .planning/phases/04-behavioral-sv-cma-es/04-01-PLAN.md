Task 1: Create stein.py with pure Stein repulsion functions

Files: accel_training/es_components/stein.py

Action:
  Create stein.py with two exported functions. No classes, no side effects, pure JAX.

  File module docstring: "Stein Variational Gradient Descent repulsion for SV-CMA-ES.
  Implements SVGD (Liu and Wang 2016) with behavior-space RBF kernel and latent-space
  gradient direction. Kernel K is NxN from behavior signature pairwise distances; repulsion
  gradient applied to CMA means in latent space (D=64). Standard median heuristic:
  h = median(sq_dists) / log(N)."

  FUNCTION: compute_stein_repulsion(means, bsigs, epsilon=0.01)
    Args: means (N, param_dim), bsigs (N, D_bsig), epsilon float
    Returns: (N, param_dim) delta to add to means
    CRITICAL dimension: K is NxN from bsigs (D=169). Gradient direction uses means (D=64).
    K @ means is (N,N)@(N,64)=(N,64). These are different spaces -- do not confuse.
    Steps:
      diff_b = bsigs[:, None, :] - bsigs[None, :, :]         # (N, N, D_bsig)
      sq_dists_b = jnp.sum(diff_b ** 2, axis=-1)              # (N, N)
      N_f = jnp.float32(means.shape[0])
      # Standard SVGD: h = median(sq_dists) / log(N). NOT median^2/log(N) (RESEARCH Pitfall 3).
      # Floor prevents NaN when all bsigs identical (median=0).
      h = jnp.maximum(jnp.median(sq_dists_b) / jnp.log(N_f + 1e-8), 1e-8)
      K = jnp.exp(-sq_dists_b / h)                            # (N, N)
      K_rowsum = K.sum(axis=1)                                 # (N,)
      repulsion = (1.0 / (N_f * h)) * (K_rowsum[:, None] * means - K @ means)  # (N, param_dim)
      return epsilon * repulsion

  FUNCTION: mean_pairwise_behavior_dist(bsigs)
    Args: bsigs (N, D_bsig)
    Returns: Python float, mean Euclidean distance over all N*(N-1) off-diagonal pairs
    If N <= 1: return 0.0 immediately (no pairs)
    Steps:
      diff = bsigs[:, None, :] - bsigs[None, :, :]
      sq = jnp.sum(diff ** 2, axis=-1)
      d = jnp.sqrt(jnp.maximum(sq, 0.0))
      mask = 1.0 - jnp.eye(N)
      return float(jnp.sum(d * mask) / (N * (N - 1)))

Task 2: Create svcmaes_strategy.py -- SVCMAESStrategy class

Files: accel_training/es_components/svcmaes_strategy.py

Action:
  Create svcmaes_strategy.py implementing SVCMAESStrategy. Mirror the module structure
  of nses_strategy.py (sys.path setup, lazy imports in tell(), docstring).

  Module docstring: Explain SV-CMA-ES: N independent CMA-ES particles with Stein
  repulsion in behavior space. State is {"particles": [{"es_state": ..., "es_params": ...}]}.
  tell() receives pre- and post-repulsion arrays (two-pass eval done in train.py).

  CLASS: SVCMAESStrategy(param_dim, pop_size)
    __init__:
      Store param_dim, pop_size.
      Create self._es_template = CMA_ES(population_size=pop_size, solution=jnp.zeros(param_dim))

    init_state(rng, config) -> dict:
      N = config.get("sv_n_particles", 2)
      sigma_init = config.get("sigma_init", 0.5)
      particles = []
      for i in range(N):
        rng, rng_i = jax.random.split(rng)
        es_params = self._es_template.default_params.replace(std_init=sigma_init)
        # Random mean init (NOT zeros -- locked CONTEXT decision; zeros cause zero Stein gradient)
        mean_i = jax.random.normal(rng_i, (param_dim,)) * sigma_init
        es_state = self._es_template.init(rng_i, mean_i, es_params)
        particles.append({"es_state": es_state, "es_params": es_params})
      return {"particles": particles}

    ask(state, rng) -> (jnp.ndarray, dict):
      Iterate over state["particles"], call evosax ask for each, collect populations.
      Concatenate: all_cands = jnp.concatenate(all_pops, axis=0)  # (N*pop_size, param_dim)
      Return (all_cands, new_state_with_updated_particles)
      Each particle ask: pop_i, new_es_state = self._es_template.ask(rng_i, p["es_state"], p["es_params"])

    tell(state, pre_cands, pre_bsigs, post_cands, post_regrets, post_bsigs, epsilon) -> (dict, dict):
      N = len(state["particles"])
      pop_size = self._pop_size
      Import from .stein: compute_stein_repulsion, mean_pairwise_behavior_dist

      # Pre-repulsion per-particle behavior sigs (mean of each particle's pop_size candidates)
      particle_pre_bsigs = jnp.stack([
        jnp.mean(pre_bsigs[i*pop_size:(i+1)*pop_size], axis=0)
        for i in range(N)
      ])  # (N, D_bsig)

      # Pre-repulsion distance metric for logging
      dist_pre = mean_pairwise_behavior_dist(particle_pre_bsigs)

      # Update each particle with post-repulsion data
      dummy_key = jax.random.PRNGKey(0)
      new_particles = []
      for i, p in enumerate(state["particles"]):
        cands_i = post_cands[i*pop_size:(i+1)*pop_size]       # (pop_size, param_dim)
        regrets_i = post_regrets[i*pop_size:(i+1)*pop_size]   # (pop_size,)
        fitness_i = -regrets_i  # negate: evosax minimizes, we maximize regret
        new_es_state, _ = self._es_template.tell(
          dummy_key, cands_i, fitness_i, p["es_state"], p["es_params"]
        )
        new_particles.append({"es_state": new_es_state, "es_params": p["es_params"]})

      # After tell(), extract updated means and apply Stein repulsion (step 7 of CONTEXT order)
      if N > 1:
        current_means = jnp.stack([p["es_state"].mean for p in new_particles])  # (N, param_dim)
        # Post-repulsion per-particle bsigs for Stein kernel
        particle_post_bsigs = jnp.stack([
          jnp.mean(post_bsigs[i*pop_size:(i+1)*pop_size], axis=0)
          for i in range(N)
        ])  # (N, D_bsig)
        repulsion = compute_stein_repulsion(current_means, particle_post_bsigs, epsilon)
        for i in range(N):
          new_mean_i = new_particles[i]["es_state"].mean + repulsion[i]
          updated_es_state = new_particles[i]["es_state"].replace(mean=new_mean_i)
          new_particles[i] = {**new_particles[i], "es_state": updated_es_state}
      # N=1: skip repulsion (zero gradient anyway; skipping is cleaner per CONTEXT)

      # Post-repulsion distance metric
      if N > 1:
        particle_post_bsigs_final = jnp.stack([
          jnp.mean(post_bsigs[i*pop_size:(i+1)*pop_size], axis=0)
          for i in range(N)
        ])
        dist_post = mean_pairwise_behavior_dist(particle_post_bsigs_final)
      else:
        dist_post = 0.0

      new_state = {"particles": new_particles}
      metrics = {"sv_behavior_dist_pre": dist_pre, "sv_behavior_dist_post": dist_post}
      return new_state, metrics
