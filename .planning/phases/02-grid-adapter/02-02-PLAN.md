**Part B: Rewrite _do_injection() for gated pipeline (injector.py)**

Replace the current `_do_injection()` method with the gated version. The method should:

1. **Refresh evaluator** (if gate enabled):
   ```python
   rng, train_state = runner_state
   if self.config.gate_enabled and self.agent_evaluator is not None:
       self.agent_evaluator.update_params(train_state.params)
   ```

2. **Extract references AND Level objects** (if gate enabled):
   ```python
   if self.config.gate_enabled and self.agent_evaluator is not None:
       references, ref_levels = self.buffer_stats.extract_references_with_levels(
           train_state.sampler
       )
   else:
       references = self.buffer_stats.extract_references(train_state.sampler)
       ref_levels = []
   ```

3. **Extract buffer summary and global_metrics**:
   ```python
   buffer_summary = self.buffer_stats.extract_buffer_summary(train_state.sampler)
   global_metrics = BufferStatsExtractor.extract_global_metrics(buffer_summary)
   ```

4. **Compute reference trajectories** (if gate enabled):
   ```python
   ref_trajectories = []
   ref_labels = []
   if self.config.gate_enabled and self.agent_evaluator is not None and ref_levels:
       for ref, level in zip(references, ref_levels):
           traj = self.agent_evaluator.evaluate_level_multi_rollout(
               level, n_rollouts=self.config.n_rollouts_gate
           )
           ref_trajectories.append(traj)
           ref_labels.append(ref.label)
   ```

5. **Build DiversityThresholds from config**:
   ```python
   thresholds = DiversityThresholds(
       difficulty_threshold=self.config.difficulty_threshold,
       min_diversity=self.config.min_diversity,
       diversity_metric=self.config.diversity_metric,
   )
   ```

6. **Generate candidates** — two code paths:
   - **Gate enabled:** Call `self.generator.generate_with_feedback()` for each seed:
     ```python
     result = self.generator.generate_with_feedback(
         agent_evaluator=self.agent_evaluator,
         reference_trajectories=ref_trajectories,
         reference_labels=ref_labels,
         references=references,
         global_metrics=global_metrics,
         diversity_thresholds=thresholds,
         max_diversity_retries=self.config.max_diversity_retries,
         n_rollouts=self.config.n_rollouts_gate,
     )
     ```
     If `result.success` and `result.gate_metrics` shows accepted: append to valid_levels and collect `result.gate_metrics.get("mean_diversity", 0.0)` into `diversity_scores` list.
     Otherwise: increment `gate_rejected` counter.

   - **Gate disabled (fallback to Phase 1 behavior):** Call `self.generator.generate(references=references, global_metrics=global_metrics)` as before, then validate with `validate_llm_level()`.

   Track `gate_accepted` and `gate_rejected` counters.

7. **Track batch_all_rejected events**:
   ```python
   if gate_accepted == 0 and self.config.n_raw > 0:
       self.batch_all_rejected_count += 1
   ```

8. **Mutation amplification** — keep the existing mutation logic from Phase 1 (Steps 4 in the current code). This operates on valid_levels regardless of how they were obtained.

9. **Buffer insertion** — keep the existing max-priority insertion logic from Phase 1 (Step 5).

10. **WandB logging** — extend `log_payload` with new gate metrics (GATE-03):
    ```python
    log_payload.update({
        "llm/diversity_score_mean": float(np.mean(diversity_scores)) if diversity_scores else 0.0,
        "llm/difficulty_score_mean": float(np.mean(difficulty_scores)) if difficulty_scores else 0.0,
        "llm/gate_rejection_rate": gate_rejected / seeds_generated if seeds_generated > 0 else 0.0,
        "llm/batch_all_rejected_count": self.batch_all_rejected_count,
    })
    ```
    Where `difficulty_scores` collects `result.gate_metrics.get("regret", 0.0)` from accepted results.

**IMPORTANT: Do NOT re-implement the feedback loop.** `generate_with_feedback()` already handles: initial generation, agent rollout, gate evaluation, diversity feedback prompt, and retries. Do NOT add a custom retry loop around it — one call per seed is correct.

**IMPORTANT: Do NOT compute reference trajectories inside the per-seed loop.** Compute them ONCE at the start of `_do_injection()` and pass the same list to every `generate_with_feedback()` call.
