**Add `from_checkpoint()` classmethod** for backward compatibility with test_generator.py:
```python
@classmethod
def from_checkpoint(cls, checkpoint_dir: str, checkpoint_step: int = -1,
                    num_steps: int = 250, seed: int = 42) -> "AgentEvaluator":
    """Load agent from checkpoint directory (backward compat for test_generator.py)."""
    from cross_evaluate import load_agent
    checkpoint_dir = os.path.abspath(checkpoint_dir)
    logger.info(f"Loading agent from {checkpoint_dir}...")
    train_state, config, env, env_params = load_agent(checkpoint_dir, checkpoint_step)
    if train_state is None:
        raise RuntimeError(f"Failed to load agent from {checkpoint_dir}")
    return cls(
        apply_fn=train_state.apply_fn,
        params=train_state.params,
        env_params=env_params,
        num_steps=num_steps,
        seed=seed,
    )
```

**Refactor `_build_rollout_fn()`:**
1. Add caching by `num_levels` — return cached fn if `self._rollout_fn is not None and self._rollout_fn_num_levels == num_levels`
2. Snapshot `self.params` into local var `params` at build time (captures into JIT closure)
3. Use `self.apply_fn` instead of `train_state.apply_fn`
4. Use local `params` instead of `train_state.params` in the inner `step()` function
5. Store result in `self._rollout_fn` and `self._rollout_fn_num_levels`

**Critical JIT detail:** The `@jax.jit` closure captures `params` by value at trace time. When `update_params()` sets `self._rollout_fn = None`, the next `_evaluate_batch()` call rebuilds the closure with the new `self.params`. JAX caches by shape not value, so re-JIT cost is minimal (traces once per `num_levels` shape).

**Update `_evaluate_batch()`:**
Change the existing code that builds rollout_fn. Currently it may store `self._rollout_fn` — ensure it calls `self._build_rollout_fn(num_levels)` which handles caching.

**Update existing callers in test_generator.py:**

If found, update the call sites to use the classmethod.
