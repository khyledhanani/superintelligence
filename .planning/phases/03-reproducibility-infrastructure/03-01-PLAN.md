**1. Create `llm/level_cache.py`** with a `LevelCache` class:

```python
class LevelCache:
    def __init__(self, run_dir: str):
        """
        run_dir: e.g. "results/<run_name>/llm_levels/"
        Creates directory on init via Path.mkdir(parents=True, exist_ok=True).
        """

    def save_accepted(self, level, step: int, idx: int, gate_metrics: dict) -> str:
        """Save accepted LLM level as .npy + JSON sidecar. Returns wall_map hash (16 hex chars).

        - wall_map: np.asarray(level.wall_map, dtype=bool) — MUST cast to bool for deterministic hashing
        - .npy file: f"step_{step:05d}_idx_{idx:03d}.npy" containing wall_map_np
        - .json sidecar: f"step_{step:05d}_idx_{idx:03d}.json" with fields:
            wall_map_hash (str, 16 hex chars), injection_step (int), batch_index (int),
            gate_scores: {td_error_emd: float|null, solve_rate: float|null},
            accept: true, timestamp: ISO 8601 UTC string
        - Hash: hashlib.sha256(wall_map_np.tobytes()).hexdigest()[:16]
        """

    @staticmethod
    def compute_hash(level) -> str:
        """Compute wall_map SHA-256 hash (16 hex chars) without saving. For WandB logging."""
```

Use stdlib only: `hashlib`, `json`, `datetime`, `pathlib.Path`. Use `numpy` for `np.asarray` and `np.save`.

**2. Wire LevelCache into `llm/injector.py`**:

- Add `from llm.level_cache import LevelCache` import at top.
- Add `level_cache` parameter to `__init__` (default `None`). Store as `self.level_cache`.
- In `_do_injection()`, after Step 4 (the per-seed generation loop) but BEFORE Step 5 (mutation amplification): iterate over `valid_levels` and call `self.level_cache.save_accepted(level, current_step, idx, gate_metrics_for_this_seed)`. Collect the returned hashes into `accepted_hashes` list. Only cache if `self.level_cache is not None`.
  - IMPORTANT: Cache only `valid_levels` (LLM seeds), NOT mutations. Per CONTEXT.md: "Only LLM-generated levels are cached."
  - For gate_metrics, use the per-seed diversity/difficulty scores already tracked in `diversity_scores[i]` and `difficulty_scores[i]`. For ungated path, pass empty dict.
- To pass `current_step` into `_do_injection()`, either: (a) add it as a parameter from `maybe_inject()`, or (b) compute it inside `_do_injection` from a stored eval_step. Option (a) is cleaner: pass `current_step` from `maybe_inject()` to `_do_injection(runner_state, current_step)`.

**3. Add WandB hash table logging** in `_do_injection()`:

After collecting `accepted_hashes`, add to `log_payload` BEFORE the `wandb.log()` call:
```python
if accepted_hashes:
    hash_table = wandb.Table(
        columns=["step", "batch_index", "wall_map_hash"],
        data=[[current_step, i, h] for i, h in enumerate(accepted_hashes)]
    )
    log_payload["llm/accepted_level_hashes"] = hash_table
```

Guard with `if accepted_hashes:` to avoid logging empty tables (Pitfall 4 from RESEARCH.md).

**IMPORTANT: Do NOT save mutations to the level cache.** Only the `valid_levels` list (direct LLM outputs that passed the gate) gets cached. Mutations are derived variants and are not part of the audit trail.
