figure with shaded std bands. Injection diagnostics (acceptance rate, total injected) are

Output: Extended compare_llm_results.py with cross-project support; results/ PNG output;
stdout comparison table. Run only after human confirms 50k runs are complete.

Score function limitation note: JAXUED_LEARNABILITY uses --score_function sfl (buffer
scoring) while JAXUED_LLM uses --score_function MaxMC. The comparison metric solve_rate/mean
is the held-out evaluation metric and is valid across both branches. The
level_sampler/mean_score metric is NOT cross-comparable and must not be used. The script
output must state this clearly.
