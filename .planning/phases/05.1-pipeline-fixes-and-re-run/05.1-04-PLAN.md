The orbax CheckpointManager for maze_plr.py saves a `train_state` pytree with `params` as a subkey.
Add a helper function `load_accel_params(checkpoint_dir)` that loads from the orbax format
and returns the same structure that `load_agent_params()` returns (a dict suitable for network.apply).

If the orbax format is complex to parse, use the simpler approach: load via pickle if
agent_params.pkl exists (ES format), otherwise load via orbax (ACCEL format). Detect by
checking whether `checkpoint_dir/agent_params.pkl` exists.

```python
def load_checkpoint_params(ckpt_path):
    """Load agent params — handles both pickle (ES runs) and orbax (ACCEL) formats."""
    pkl_path = os.path.join(ckpt_path, 'agent_params.pkl')
    if os.path.exists(pkl_path):
        return load_agent_params(ckpt_path)  # existing function
    else:
        # orbax format: load via orbax CheckpointManager
        # maze_plr.py uses: checkpointManager.save(step, train_state)
        # The pytree is train_state which has .params as the agent params
        import orbax.checkpoint as ocp
        checkpointer = ocp.PyTreeCheckpointer()
        restored = checkpointer.restore(ckpt_path)
        # restored is the train_state pytree — extract params
        # Structure depends on how maze_plr.py defines TrainState
        # Try: restored['params'] or restored.params
        if isinstance(restored, dict) and 'params' in restored:
            return restored['params']
        else:
            # Fallback: return restored as-is and let network.apply handle it
            return restored
```
