## Decisions Made

- **WANDB_RUN_GROUP env var**: maze_plr.py has no --group argparse flag (group= inside wandb.init is hardcoded to config["run_name"]). Used WANDB_RUN_GROUP environment variable instead — WandB env vars take precedence over wandb.init kwargs, so this correctly groups the run.
- **Clamp radius 3.0**: VAE is trained with standard normal prior N(0,1)^64; 3 sigma covers 99.7% of training distribution. Clamping at ±3.0 is conservative but prevents runaway drift over 5000+ Stein steps.
- **Standalone script not chained**: The original cuSolver handle failure (ACCEL CUDA fatal error) occurred because ACCEL was launched immediately after SV-CMA-ES exited in the same sequential script, with GPU memory not fully released. The fix is to run ACCEL in a fresh tmux window on a clean GPU.
