  <files>llm/buffer_stats.py</files>
  <action>
Create `llm/buffer_stats.py` containing a class `BufferStatsExtractor` that converts a live `train_state.sampler` JAX dict into `ReferenceMaze[]` objects suitable for LLM prompt context. This replaces the .npz-based flow in `llm/test_generator.py` with a live-buffer flow.

The class should:

1. **`__init__(self, n_references: int = 5, strategy: str = "hardest")`** -- stores config for reference selection.

2. **`extract_references(self, sampler: dict) -> List[ReferenceMaze]`** -- the main method:
   - Read `sampler["size"]` to get active level count.
   - Read `sampler["scores"][:size]` as numpy (via `np.asarray()`).
   - Read `sampler["levels"]` (a batched Level pytree) sliced to `[:size]`.
   - Select top-N references by score (strategy="hardest" = top regret = highest scores). Use `np.argsort(scores)[::-1][:n_references]` like `test_generator.select_references()` does for "top_regret".
   - For each selected index, extract the Level at that index from the batched levels using `jax.tree_util.tree_map(lambda x: x[idx], levels)`.
   - Convert each Level to ASCII grid via `level.to_str()`.
   - Create a `ReferenceMaze(grid=ascii_grid, label=f"Maze {chr(65+i)}", metrics=[MetricEntry(name="Regret Score", value=float(scores[idx]), description="Agent's learning potential", higher_is="more to learn", metric_key="scalar_regret")])` for each.
   - Return the list of ReferenceMaze objects.

3. **`extract_buffer_summary(self, sampler: dict) -> dict`** -- returns a summary dict with:
   - `buffer_size`: int (sampler["size"])
   - `mean_score`: float
   - `max_score`: float
   - `min_score`: float
   - `score_std`: float
   These are useful for WandB logging and potentially for `global_metrics` in prompt building.

Important implementation notes:
- All JAX array reads must go through `np.asarray()` to convert to numpy before Python operations.
- The `sampler["levels"]` is a JAX pytree (Level struct with batched arrays). Use `jax.tree_util.tree_map(lambda x: x[idx], sampler["levels"])` to extract a single Level.
- The Level's `to_str()` method returns the ASCII grid. This works on both JAX and numpy-backed Level objects.
- Do NOT import from `llm/test_generator.py` -- this module should be self-contained (it replaces the file-based flow).
- Import `ReferenceMaze` and `MetricEntry` from `llm.prompt_builder`.
- Import `jax` and `numpy as np` for array operations.
