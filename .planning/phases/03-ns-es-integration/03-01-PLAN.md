```python
class CMAESStrategy:
    def __init__(self, param_dim: int, pop_size: int):
        from evosax.algorithms import CMA_ES
        dummy_solution = jnp.zeros(param_dim)
        self._es = CMA_ES(population_size=pop_size, solution=dummy_solution)
        self._param_dim = param_dim
        self._pop_size = pop_size
        self._dummy_solution = dummy_solution

    def init_state(self, rng, config):
        es_params = self._es.default_params
        if "sigma_init" in config:
            es_params = es_params.replace(std_init=config["sigma_init"])
        mean = config.get("mean", self._dummy_solution)
        es_state = self._es.init(rng, mean, es_params)
        return {"es_state": es_state, "es_params": es_params}

    def ask(self, state, rng):
        population, new_es_state = self._es.ask(rng, state["es_state"], state["es_params"])
        return population, {**state, "es_state": new_es_state}
```

  - Identical to CMAESStrategy.init_state — copy verbatim

ask(self, state, rng):
  - Identical to CMAESStrategy.ask — copy verbatim
  - Per locked CONTEXT.md decision: "ask() behavior identical to CMAESStrategy; NS-ES distinction is entirely in fitness computation before tell()"

tell(self, state, candidates, regrets, candidate_sigs, buffer_sigs, valid_mask, alpha, beta, k=5):
  - This tell() signature differs from ESStrategy Protocol (which has 3 args). Document in docstring: "NSESStrategy.tell() extends the Protocol minimum surface with novelty inputs. The caller in train.py uses the concrete type, not the Protocol abstraction."
  - Implementation:
    1. Lazy import compute_novelty_batch and compute_fitness_batch inside tell() body to avoid circular import
    2. novelties = compute_novelty_batch(candidate_sigs, buffer_sigs, valid_mask, k=k)
    3. composite = compute_fitness_batch(regrets, novelties, alpha=alpha, beta=beta)
    4. fitness_for_evosax = -composite  (evosax minimizes; we maximize composite)
    5. dummy_key = jax.random.PRNGKey(0)
    6. new_es_state, _ = self._es.tell(dummy_key, candidates, fitness_for_evosax, state["es_state"], state["es_params"])
    7. mean_novelty = float(jnp.mean(novelties))
    8. return {**state, "es_state": new_es_state}, mean_novelty
  - Returns TUPLE (new_state_dict, mean_novelty_float) — train.py unpacks both

Do NOT create a separate novelty archive. Per locked CONTEXT.md decision: "Novelty source: NSESStrategy reads behavior signatures from the replay buffer for k-NN novelty computation. No separate novelty archive — one data structure, no duplication." Buffer state is passed in at call time via buffer_sigs + valid_mask.
